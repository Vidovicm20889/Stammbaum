1. Funktionsname bekannt → `Grep` auf den Namen **in dieser Datei** (Teil 2) → eine kurze Zeile

2. Nur das Thema bekannt → Abschnittstabelle (Teil 1) → Zeilenbereich → dort gezielt lesen.
